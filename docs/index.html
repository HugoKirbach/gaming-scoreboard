    Pour apparaître, chacun doit rendre son historique de jeu visible : sur PS5, Paramètres › Utilisateurs et comptes › Confidentialité, puis dans la rubrique Jeux | Médias, régler qui peut voir l'historique de jeu sur Tout le monde.

      Le PSN n'enregistre le temps de jeu qu'à la fermeture du jeu : chaque hausse vue lors d'un relevé correspond à une session terminée depuis le relevé précédent. Les horaires sont donc estimés avec une fourchette, d'autant plus large que les relevés sont espacés (un relevé automatique par jour, à 3 h, plus ceux lancés à la main).
